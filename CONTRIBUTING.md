# Collaboration routine

1. Create a short-lived branch named `codex/<scope>` from the current shared base.
2. Keep each pull request focused on one roadmap task and include the relevant automated checks.
3. Request one reviewer before merge. The author addresses comments and the reviewer confirms the final change.
4. Do not commit secrets, derived artifacts, organizer answer-key material, or edits to `data/`.
5. Record a short implementation note in the applicable roadmap phase after the team completes it.
